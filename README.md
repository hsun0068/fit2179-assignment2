# Australia Health & Lifestyle

This is a submission-style FIT3179 Data Visualisation 2 draft.

## Purpose
The visualisation explores health and lifestyle patterns in Australia using:
- state and territory lifestyle risk rankings
- regional health-risk bubble plots
- interactive filtering
- national trend brushing
- age-sex heatmap interaction
- grouped and stacked bar charts
- a compact final summary dashboard

## Important data note
The visualisation is structured to support official ABS or other approved health and lifestyle datasets.

## How to run locally
1. Open the full folder in VS Code.
2. Right-click `index.html`.
3. Select `Open with Live Server`.

## GitHub Pages
Upload `index.html`, `css`, `data`, `js`, and this README to the root of your GitHub repository.
Then enable GitHub Pages from `main` branch and `/root`.
